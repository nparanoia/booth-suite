# Demo 脚本：客服直写冒烟（约 3 分钟）

前置：cloud 网关 8080、agent 8091、web 5173；演示账号见 `booth-cloud/docs/DEMO-DATA.md`。

1. **登录前台** → 店内客服。  
2. 点「问退货政策」→ 出现政策答复与 **知识来源** 折叠。  
3. 点选一笔 **已完成** 订单 chip（或口播完整单号）→「申请退货」→ 对话内提示售后已提交（**无确认卡**）。  
4. 再发同一句退货 → 回复含「未重复建单」，商城售后仍 1 条。  
5. （可选）口播他人订单号查单 → 「订单不存在」。  
6. （可选）**待发货** 单改地址，推荐句式：  
   `把订单 <单号> 地址改成 北京市朝阳区测试路88号 收件人王五 手机13900001111`  
   或：`改地址 收货人张三 手机13800138000 地址上海市浦东新区示范路1号`  
7. **店主后台** `/admin` → 今日店况 / 售后；有权限码时菜单按 `can()` 过滤。
