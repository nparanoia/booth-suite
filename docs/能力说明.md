# Booth 能力说明（对外材料稿）

> 与代码一致的诚实边界；细节以各仓 README / `SECURITY.md` / `写操作约定.md` 为准。

## 1. 三仓架构

```text
浏览器 (booth-web)
   │  /gw/*          /agent/*
   ▼                 ▼
booth-gateway:8080   booth-agent:8091
   │                    │ 工具调用 / 透传 Bearer
   ├─ booth-user
   ├─ booth-product
   └─ booth-trade  ←───┘
         ▲
   MySQL / Redis / Rabbit / Nacos
Agent 另用 PostgreSQL+pgvector（知识库 / outbox）
```

可选：`--profile search`（ES + booth-search）、`--profile obs`（Prometheus / Grafana / Zipkin）。

## 2. 能力映射

| 能力 | 落点 | 不宣称 |
|------|------|--------|
| 查单 / 物流摘要 | Agent `query_order` → 网关 | 全渠道履约中心 |
| 政策问答 + RAG | `search_policy` + pgvector；web 展示 sources | RAGAS / 完美召回 |
| 退货 / 取消 / 改地址 | 对话内直写 + 指纹/outbox 幂等 + 写熔断 | 确认卡；凭证/试算/退款进度查询 |
| 越权防护 | 商城归属校验；Golden 含 IDOR | 完整 WAF |
| 人工 | `transfer_human` 给店主电话 | 呼叫中心 / 多坐席 |
| 支付 | Mock + 支付宝接口预留 | 真沙箱已跑通 |
| 可观测 | chat_transcript、ops summary、可选 Prometheus | 完整 OTel |
