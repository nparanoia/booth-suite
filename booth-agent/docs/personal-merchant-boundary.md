# 个人商户 Agent：大厂能力裁剪边界

日期：2026-11-01（保留包按讨论定稿；重叠块 1–10 已落地）。对象是 Booth **个人自营**（单店主、一套政策、对接 `booth-cloud`）。  
本文件锁定「省略 / 保留」。省略 ≠ 否定大厂价值。  
**保留包 = 能力承诺**；第三节标注各块落地状态。

## 场景前提

- 不是多店铺平台；无平台客服 vs 店铺客服双角色。
- 售前：知识库支撑商品/活动说明；**不做**个性化导购引擎。店主**必须有**补知识/活动的入口。
- **转人工**：用户要人工 → 回复**固定电话**（可写清大致时段，非 7×24）。不做留言店主、不做座席排队、不做企微多渠。
- **投诉取证**：对话与工具轨迹**入库持久化**（可设保留天数），管理端可查；不能聊完就没了。

## 裁剪原则

- 万店/万人/大促的组织平台能力 → 省略。
- 碰钱、碰权、碰身份、碰投诉证据 → 保留或简化落地。
- 峰值：要有限流、降级、写熔断、过载拒绝；**不做排队服务**（流量不必）。

## 二、必须保留包（2026-11-01 定稿）

下列为与大厂**同构或同族瘦身**后必须具备的能力。括号内：大厂对齐点 → 个人改动 → 落地状态。

### 1. 身份与越权（已有）

- **大厂对齐：** 登录态贯穿工具，中台鉴权防扫单。  
- **个人：** Bearer 透传；商城校验归属；确认票校验本人。无租户维。  
- **合理：** 同构。

### 2. 读写分离与写操作（退货 / 取消 / 改地址）（已落地）

- **大厂对齐：** 查可自动；办 = 预校验 →（可选确认）→ 幂等提交。  
- **个人：** **校验后对话内直写**（无确认卡）；技能含**退货、取消、改地址**（待发货）；参数指纹 + `write_action_outbox` 幂等；写熔断。不做催发货/发票。  
- **合理：** 防误触靠校验与幂等，不靠二次点击确认卡。

### 3. 受控工具循环 + 降级（已有）

- **大厂对齐：** 白名单、步数、超时、错误分类；模型失败走规则/模板。  
- **个人：** 同；无多 Agent 网格。  
- **合理：** 同构瘦身。

### 4. 知识拒答 + 店主补库必做（已落地）

- **大厂对齐：** 可运营知识 + 拒答 + 引用；常有配置台。  
- **个人：** pgvector + 短语 + 拒答 + 来源；**管理端** `/app/ops/knowledge` 增删；活动说明带 **valid_from / valid_to**，检索过滤过期。  
- **合理：** 检索形态同族；补库为必做入口。

### 5. 会话业务态 + 入口带单必做 + 原文 10 轮（已落地）

- **大厂对齐：** 入口注入业务实体 + 槽位状态机 + 短窗口原文。  
- **个人：** 结构化订单号/步骤/确认票；入口 `contextOrderSn`；最近 **10 轮**原文；空闲超时后清窗口保单号。  
- **合理：** 与大厂记忆分层一致。

### 6. 可验证 GoldenSet（已有）

- 离线黄金集 + `target/golden-metrics.json`；不做 RAGAS。

### 7. 峰值瘦身（已落地）

- 用户限流、工具超时、模型→规则降级、**writeCircuitOpen 写熔断**、过载 **429 拒绝**。  
- **不做**排队服务。

### 8. 人工电话兜底（已落地）

- 意图 HUMAN → `transfer_human` → 配置中的店主电话与时段。

### 9. 对话取证入库（已落地）

- `chat_transcript` 表；对话双写 PG；管理端 `/app/ops/chats` 按会话/会员/单号查。  
- Redis 仍管热会话与确认票。

### 10. 工程安全约束（部分已有）

- 仓库可公开基线；真商用另册升配。

### 附：活动时效与功能开关（已落地）

- 知识时效过滤；`skills.changeAddressEnabled` / `humanTransferEnabled`。
