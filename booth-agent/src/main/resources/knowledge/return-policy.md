# 退换货政策

## 七天无理由退货

已签收的商品，自签收之日起 7 天内，可申请七天无理由退货。商品需未使用、附件齐全、不影响二次销售。

以下情况不适用七天无理由：

- 个人定制类商品
- 鲜活易腐商品
- 拆封后易影响健康的商品（如贴身衣物，以商品页说明为准）

## 质量问题退货

收到商品存在质量问题，可在签收后 15 天内申请退货或换货。需要提供问题照片，售后审核通过后寄回。

## 申请方式

在订单详情中选择需要退货的商品明细，填写退货原因后提交。一个订单明细只能申请一次售后。

仅「已完成」状态的订单可以申请退货。待付款、待发货、已关闭的订单不能申请。

## 退款时效

仓库验货通过后，退款一般在 3～7 个工作日内原路退回。
