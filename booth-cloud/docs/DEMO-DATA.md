# 演示数据说明

Flyway 会在各库首次迁移时写入管理员与（商品）演示目录；订单需下单产生。

## 账号（仅本地）

| 角色 | 用户名 | 密码 | 入口 |
|------|--------|------|------|
| 店主后台 | `admin` | `admin123` | `booth-web` → `/admin` |
| 会员 | 自行注册 | — | 前台 `/login` |

- 演示默认 **`SUPER_ADMIN`**（权限码 `*`）：后台菜单按 `admin.can(权限码)` 过滤；接口仍服务端鉴权。  
- 登录失败按 IP 限流（约 15 分钟内 10 次），降低撞 `admin123` 成功率。  

部署后请立即修改 `admin` 密码。公开仓 README 须醒目标「仅本地演示」。

## 商品种子

`booth-product` 迁移 `V2__seed_demo_catalog.sql` 写入：

- 品牌「Booth 自营」、分类「日用」
- 上架商品「演示马克杯」及 SKU（库存充足）
- 一条首页轮播占位

空库启动 product 服务后前台应能看到该商品。若数据卷是旧库且无此迁移，可清卷重建或手工在后台上架。

## 客服联调建议订单

在前台用会员账号：

1. 下单演示商品 → Mock 支付（若开启）→ 后台发货 → 确认收货，得到 **已完成** 单，可测退货  
2. 另下一单停在 **待付款**，可测取消  
3. 待发货单可测改地址  

智能客服从订单详情「找客服」带 `orderSn` 进入。Agent 需已启动且 `BOOTH_GATEWAY_BASE_URL` 指向网关。

## 支付宣称

本地默认 **Mock 支付 + 接口预留**；无真支付宝沙箱密钥时不要宣称已跑通沙箱。
